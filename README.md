# 一箭又一箭 - Arrow Puzzle Game

## 游戏简介

"一箭又一箭"是一款休闲益智解谜游戏。玩家需要观察棋盘上箭头的方向和相互阻挡关系，按照合适的顺序点击箭头，使所有箭头依次飞出棋盘。

**游戏规则：**
- 棋盘中有带方向的箭头（上、下、左、右）
- 点击箭头后，检查其前进方向是否有其他箭头阻挡
- 如果无阻挡，箭头沿方向飞出棋盘并消失（带飞行动画）
- 如果有阻挡，箭头不消失，并消耗一次失误机会
- 在有限失误次数内清除所有箭头即可通关
- 失误次数耗尽则游戏结束

## 开发环境

- Python 3.8+
- Pygame 2.0+
- Windows 10/11（其他系统也可运行）

## 安装和运行方法

### 1. 安装 Python
确保已安装 Python 3.8 或更高版本。可从 [python.org](https://www.python.org/) 下载。

### 2. 安装 Pygame
打开终端或命令提示符，运行以下命令：
```bash
pip install pygame
```

### 3. 运行游戏
```bash
python main.py
```

### 4. 运行自动测试（可选）
```bash
python test_game.py
```
后台运行，不弹窗口，直接输出 T01~T11 各项的通过情况。

## 游戏操作说明

### 主菜单
- 点击"开始游戏"按钮进入游戏

### 游戏界面
- **鼠标点击**：选择并点击箭头
- **重新开始按钮**：界面右下角的按钮，效果和 R 键一致
- **R 键**：重新开始当前关卡
- **空格键**：关卡通过后进入下一关
- **ESC 键**：返回主菜单

### 游戏提示
- 箭头朝向表示其飞出方向
- 箭头前方不能有其他箭头才能飞出
- 注意失误次数限制

## 关卡设计

游戏包含 4 个关卡，难度逐渐递增：

1. **关卡 1**：简单入门，3 个失误次数
2. **关卡 2**：基础挑战，3 个失误次数
3. **关卡 3**：进阶难度，3 个失误次数
4. **关卡 4**：最终挑战，3 个失误次数

每个关卡都经过实际试玩验证，确保存在合理的通关顺序。

## 技术实现

### 核心类
- **Arrow**：箭头类，管理箭头状态和动画
- **Level**：关卡类，存储关卡数据
- **Game**：游戏主类，管理游戏逻辑和界面

### 路径检测算法
根据箭头方向检查同行/同列是否有其他箭头：
- 右箭头：检查右侧同行是否有箭头
- 左箭头：检查左侧同行是否有箭头
- 下箭头：检查下方同列是否有箭头
- 上箭头：检查上方同列是否有箭头
